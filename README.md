# Task7-String-Processing-for-Data-Cleaning-
String Processing for Data Cleaning

Description

This project demonstrates Python string operations used to clean and standardize text data.

Operations Used

- "strip()" – Removes extra spaces.
- "lower()" – Converts text to lowercase.
- "upper()" – Converts text to uppercase.
- "replace()" – Replaces characters or words.
- "split()" – Splits text into parts.

Examples

- Cleaning names and emails.
- Removing unwanted spaces.
- Standardizing category values.

Tools Used

- Python
- Jupyter Notebook

Objective

To learn basic text-cleaning techniques for real-world datasets.
